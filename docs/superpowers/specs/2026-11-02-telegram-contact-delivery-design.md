# Доставка заявок в Telegram

## Цель

Заменить недоступную с VPS отправку через SMTP на доставку заявок в закрытую Telegram-группу, не меняя внешний вид и поля формы на главной странице и странице персонала.

## Выбранный подход

Серверный `POST /api/contact` после существующей проверки origin, размера запроса, лимита частоты, honeypot и схемы данных отправляет форматированное сообщение через официальный Telegram Bot API `sendMessage`. Выбран закрытый групповой чат: сейчас доступ имеет владелец сайта, позднее в группу можно добавить менеджеров без изменения сайта.

Рассматривались личный чат с ботом и закрытая группа. Личный чат немного проще, но группа удобнее для будущей команды, поэтому выбран второй вариант.

## Конфигурация и безопасность

- `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` хранятся только в серверном `.env.local`.
- Токен не попадает в браузер, Git, журналы или текст ответа API.
- SMTP-переменные, `nodemailer` и почтовый пароль больше не используются.
- При ошибке Telegram публичный API возвращает прежний безопасный `DELIVERY_ERROR`, без раскрытия ответа Telegram.
- У запроса к Telegram будет таймаут, чтобы Nginx не ожидал до `504`.

## Формат заявки

Сообщение содержит заголовок «Новая заявка EVENT CREW», имя, телефон, Telegram клиента, период мероприятия, выбранные виды персонала, количество и комментарий. Пустые необязательные поля показываются знаком `—`. Пользовательский текст передаётся безопасно без Telegram-разметки.

## Проверка

- Модульные тесты форматирования и отправки в Telegram.
- Тесты API для успешной доставки, отсутствующей конфигурации, ошибки Telegram и таймаута.
- Существующие тесты формы, schema, origin, rate limit и honeypot остаются действующими.
- Полный прогон тестов, typecheck, lint и production build перед публикацией.

## Развёртывание

Владелец создаёт бота через `@BotFather`, добавляет его в закрытую группу и один раз отправляет сообщение в группу. На сервере определяются `chat_id` и токен записывается в `.env.local`; затем выполняются обновление кода, сборка и перезапуск сервиса. Отправка проверяется тестовой заявкой с сайта.
